# QA Audit Report

## 1. Audit Scope
The objective of this audit was to identify UI quirks, layout responsiveness, cross-platform functional inconsistencies and accessibility issues across the Cynbit website.

## 2. Test Environment Matrix

| Parameter | Environment 1 (Desktop) | Environment 2 (Mobile) |
| :--- | :--- | :--- |
| **Device / OS** | Windows / Laptop | Android Mobile |
| **Browser** | Google Chrome (Latest) | Google Chrome Mobile |
| **Viewport** | 1920 x 1080 (Desktop) | 393 x 851 (Mobile View) |
| **Input Method** | Mouse / Keyboard | Touchscreen |

## 3. Testing Methodology
- **Exploratory Testing:** Evaluated core user navigation, hover effects and call-to-action click responses.
- **Cross-Platform Verification:** Verified functional behavior across Desktop vs. Android viewports.
- **Visual & Typography Inspection:** Inspected container overflow rules, typographic rendering and layout alignment.
